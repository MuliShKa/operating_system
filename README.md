# Songdo Edge Intelligence

Starting directory structure for the Songdo Edge Intelligence project.
Implementation files have intentionally not been added yet.

```text
config/                 Project configuration
container/              Container files
data/
  backups/               Backup files
docs/handbook/           Handbook source files
integration/             Integration components
scenarios/               Scenario definitions and runner
scripts/                 Setup and launch scripts
sources/                 External data source registry
sql/                     Database schema
src/
  edge/                  Edge services
  ui/static/             Static web interface
systemd/                 Service definitions
tests/                   Automated tests
```
